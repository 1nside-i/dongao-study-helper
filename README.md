# 东奥海南继续教育 · 学习助手 (`dongao_study_helper_user.js`)

适用于东奥海南继续教育平台的 Tampermonkey 用户脚本（当前版本 `v1.1.0`）。点击右下角悬浮面板的「启动」按钮可开始新任务。脚本按列表顺序播放待学习的讲次与课程，并在播放结束后回到讲次列表读取平台进度。

## 适用范围

脚本仅在以下 3 类页面生效（顶层窗口，`@noframes`）：

| 页面类型 | 匹配地址 | 主要职责 |
| :--- | :--- | :--- |
| 课程列表页 | `https://study.dongao.cn/study/u/myCourseHN*` | 识别未完成课程、常驻保活会话、向工作标签页中继下一门课地址 |
| 讲次列表页 | `https://jxjycwweb.dongao.cn/cwweb/lecture/lectureList*` | 解析讲次进度、顺序进入未完成讲次、核验已播讲次是否达标 |
| 视频播放页 | `https://jxjycwweb.dongao.cn/cwweb/videoShow/video/videoPlay*` | 自动起播、后台防暂停、关闭挂机提醒、监测验证弹窗与播完跳转 |

## 核心功能

- **手动启动与全局停止**。点击「启动」开始新任务，已开始的任务可在目标页面接续。点击「停止」会同步停止任务并暂停受控视频。
- **跨子域多标签协同**。脚本通过 Tampermonkey 的 `GM_*` 存储在两个东奥子域之间同步状态，并用带心跳续期的执行权租约协调标签页，减少重复启动和同时播放。
- **课程页常驻中继**。保持「我的课程」标签页开启时，该页按默认 3 分钟间隔向同域地址发送保活请求。一门课的讲次处理完毕后，课程页查找下一门待学习课程，并将讲次列表地址传给工作标签页。
- **讲次与播放页同页跳转**。脚本尝试在当前标签页打开播放器。若入口点击后未触发跳转，会尝试用页面已有的动态参数构造同域 `videoPlay` 地址。
- **播放页自动唤起与卡顿自愈**：兼容 Video.js 延迟加载与 `<video>` 节点动态替换；当检测到元数据就绪或 UI 处于暂停态时自动唤起播放，并通过周期巡检对卡顿视频进行重新起播或单次自动刷新恢复。
- **后台/最小化防暂停**：视频加载出有效时长并正常起播后，启用页面级防暂停守卫，拦截非用户操作触发的窗口失焦/最小化暂停，并按阶梯延迟自动恢复播放。
- **自动防挂机与关弹窗**：每 25 秒模拟一次轻量鼠标移动以重置无操作计时器；若弹出“您有好久没有动了，快快动一下鼠标”等挂机提醒弹窗，自动点击「确定/继续」类按钮并恢复播放。
- **播放后核验与补播**。视频结束后默认等待 2 秒，再返回讲次列表。脚本根据完成文案、已学时长、「重新学习」等入口和时长差额判断是否继续。每轮最多核验 4 次，每讲最多自动补播 2 次。
- **尊重人工干预与合规边界**：
  - 前台手动暂停会被识别并挂起任务，不会强制续播；
  - 检测到滑块、人脸识别、扫码、图形验证码等验证弹窗时立即暂停任务并等待用户手动完成，绝不尝试绕过验证；
  - 不修改播放倍速、不拖拽跳过进度、不调用学分结算接口、不点击“下载讲义”类链接；
  - 账号匹配使用本地短哈希。任务状态和标签页地址等协调数据保存在浏览器本地，运行日志显示在面板和控制台。

## 安装方法

1. 在浏览器中安装 Tampermonkey。如果 Chrome 或 Edge 中的脚本未生效，检查扩展详情页中的「允许用户脚本」等运行权限。参见 [Tampermonkey 官网](https://www.tampermonkey.net/)和 [用户脚本权限说明](https://www.tampermonkey.net/faq.php?ext=fcmf&q=Q209&updated=true&version=4.19.6175)。
2. 打开 Tampermonkey 管理面板，点击「添加新脚本」。
3. 将 [dongao_study_helper_user.js](./dongao_study_helper_user.js) 的全部代码复制到编辑器，覆盖默认模板。保存并启用脚本，再刷新课程页，确认面板显示 `v1.1.0`。

## 使用说明

### 推荐用法（多门课程自动连播）

1. 登录东奥海南继续教育平台，进入「我的课程」页面（`https://study.dongao.cn/study/u/myCourseHN`）。
2. 页面右下角会出现橙色标题的 **东奥学习助手** 悬浮面板，点击 **启动**。
3. **保持「我的课程」标签页开启**，不要关闭。脚本会自动打开工作标签页依次播放各讲次；本课全部讲次完成后，「我的课程」页会自动将下一门未完成课程中继至工作标签页继续播放。

### 从指定课程或讲次开始

- 也可以在某门课的「讲次列表」页点击 **启动**，或从「视频播放」页的当前讲次开始。只想播放某一讲时，可用 **停止** 结束任务。
- 没有可用的「我的课程」标签页时，脚本会在当前课程的讲次处理完毕后结束本轮任务。

### 悬浮面板按钮说明

点击面板顶部的橙色标题栏可以展开或收起实时运行日志。

| 按钮 | 显示时机 | 功能说明 |
| :--- | :--- | :--- |
| **启动** | 未启动、已停止、已暂停或当前标签处于待命态 | 启动新一轮自动化任务，或在执行权空闲/过期时由当前标签接管任务 |
| **停止** | 任务运行中或暂停态 | 立即终止全局任务、暂停当前播放页视频并释放执行权 |
| **继续播放** | 播放页出现手动暂停、自动播放被拦截或验证阻塞 | 在确认无验证弹窗后恢复当前视频播放与任务执行 |
| **重试** | 任务因异常进入「已暂停（需处理）」状态 | 保持原目标课程与讲次身份不变，重新尝试当前步骤或核验 |
| **手动打开** | 页面跳转被浏览器弹窗策略拦截时 | 借助本次人工点击手势重新触发原目标课程或讲次的真实入口 |

## 架构与实现概览

脚本采用单文件 IIFE 结构，各模块职责清晰解耦：

| 模块 | 说明 |
| :--- | :--- |
| `Core` | 纯决策逻辑（不接触 DOM）：时长解析、状态文案分类（否定语义优先）、尾差容限计算、讲次/课程完成判定、下一目标选择与租约过期判定 |
| `CourseAdapter` / `LectureAdapter` / `PlayerAdapter` | 三类页面的独立 DOM 适配器，负责解析表格、定位真实入口、读取动态 URL 参数、识别验证与挂机弹窗 |
| `Store` | 基于 `GM_*` 的跨子域共享存储与变更监听（无 GM 权限时降级为 `localStorage` 并给出警告） |
| `installSameTabNavGuard` / `installPagePlayGuard` | 注入主世界的轻量守卫脚本，分别负责同页跳转/课程地址捕获与后台防暂停/Video.js 唤醒 |
| `Timers` / `StepTimers` / `Listeners` | 全局与步骤级定时器、事件监听器统一登记与清理，防止停止或切换状态后产生残留回调 |
| `UI` | 右下角轻量化中文控制面板，实时展示任务状态、当前课程/讲次、提示信息与滚动日志 |

## 关键配置项 (`DEFAULT_CONFIG`)

如需微调等待时长或核验策略，可直接修改脚本顶部的 `DEFAULT_CONFIG` 常量（自动化测试环境也可通过 `window.__DAH_TEST_CONFIG__` 覆盖）：

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `domWaitMs` / `videoWaitMs` | `20000` / `30000` ms | 等待课程/讲次表格与 `<video>` 元素出现的超时时间 |
| `leaseTtlMs` / `bgLeaseTtlMs` | `20000` / `90000` ms | 基础租约有效期 / 隐藏标签页判断自己持有的租约时使用的宽限期 |
| `heartbeatMs` | `5000` ms | 执行器心跳与租约续期间隔 |
| `handoffWaitMs` | `4500` ms | 跨页交接等待新页面确认（ack）的超时上限 |
| `sameTabDirectFallbackMs` | `1800` ms | 讲次入口点击后触发同页直达兜底的等待时间 |
| `courseRelayWaitMs` | `5000` ms | 等待课程页中继的基础时间。检测到课程页在线时至少等待 12 秒 |
| `courseKeepAliveMs` | `180000` ms | 「我的课程」页后台会话保活间隔（3 分钟） |
| `mouseKeepAliveMs` | `25000` ms | 播放页模拟鼠标微移防挂机间隔（25 秒） |
| `initialVerifyWaitMs` | `2000` ms | 视频播完后返回讲次列表核验前的初始等待时间 |
| `completeToleranceSec` | `60` s | 时长差额基础容限。至少 180 秒的讲次取基础值与总时长 3% 的较大值，上限 120 秒。更短讲次使用不同容限 |
| `maxVerifyChecks` / `retryBackoffMs` | `4` 次 / `[6000, 10000, 15000]` ms | 每轮核验次数上限（含首次核验）与再次刷新前的等待间隔 |
| `maxAutoReplaysPerLecture` | `2` 次 | 单讲次服务端时长未达标时的最大自动补播次数 |
| `stallCheckMs` | `20000` ms | 播放卡顿巡检周期 |
| `maxCourseHops` | `40` 次 | 单次运行最大课程切换次数（防死循环保护） |

## 调试接口

可以在浏览器控制台通过 `window.__DONGAO_HELPER__` 查看调试信息。任务对象和日志可能含有课程名、账号指纹或带账号参数的页面地址，分享前请检查并遮盖个人标识。

- `window.__DONGAO_HELPER__.version`：当前脚本版本号
- `window.__DONGAO_HELPER__.state()`：查看当前页面类型、标签 ID、任务状态、租约状态、暂停归因及 `<video>` 绑定状态
- `window.__DONGAO_HELPER__.log()`：返回内存中的最近运行日志（最多 200 条）
- `window.__DONGAO_HELPER__.Core` / `.adapters` / `.pages`：用于单元测试或 DOM 解析诊断

## 注意事项与限制

- **跨子域权限依赖**：脚本依赖油猴的 `GM_*` 存储进行跨子域协调。若在不支持或未授权 `GM_*` API 的环境中运行，脚本会退化为 `localStorage`，届时 `study.dongao.cn` 与 `jxjycwweb.dongao.cn` 之间无法共享任务状态。
- **浏览器自动播放限制**。遇到自动播放被拦截（`NotAllowedError`）时，点击面板的 **继续播放** 或页面播放按钮。
- **登录失效与安全验证**：若检测到密码输入框或登录过期提示，或出现滑块/人脸/扫码等安全验证弹窗，脚本会自动暂停并提示人工处理。
- **平台学习进度与学分**。播放结束后，如果站点进度接近达标且趋于稳定，脚本可能在本轮将该讲次视为完成。进入补播流程后，若已用完补播次数或找不到播放入口，脚本也可能继续下一讲。平台此时仍可能显示未完成。请刷新原讲次列表核对进度，学分与考核结果以平台显示为准。
